# 💡 Идеи для реализации

## Источники контента

- **Онлайн-школы (Skillbox, GeekBrains, Яндекс Практикум)** — захардкодить топ-10 курсов по популярным темам с ценами. API у них закрытый, обновлять вручную раз в месяц.
- **Habr** — парсинг статей по тегам. API закрытый, но страницы статичные — несложно реализовать.
- **VK Видео / YouTube** — поиск видео по теме. YouTube работает медленно в РФ, VK Видео стабильнее но контента меньше.

## Функциональность

- **Диагностика знаний** — вместо ручного выбора уровня пользователь проходит мини-тест из 3-5 вопросов, ИИ определяет уровень автоматически.
- **Практические задания** — в каждом этапе трека добавить одно конкретное задание от ИИ.
- **Проверка заданий** — пользователь вставляет своё решение, GigaChat проверяет и даёт обратную связь.
- **Сохранение прогресса** — пользователь отмечает пройденные этапы и возвращается к треку.

# 🚀 Прогрессоры — ИИ-навигатор по обучению

Персональный ИИ-помощник для построения индивидуального трека онлайн-обучения. Пользователь указывает цель, время и бюджет — система автоматически диагностирует уровень знаний и строит оптимальный маршрут с подборкой реальных курсов.

## Что умеет

- **Автоматическая диагностика уровня** — GigaChat генерирует 4 вопроса по теме, уровень определяется по ответам (формула, без лишнего вызова ИИ)
- Учитывает ответы диагностики при составлении трека — не повторяет уже освоенные темы
- Строит персональный трек обучения по этапам под определённый уровень
- Учитывает доступное время и бюджет
- Проверяет реалистичность параметров до начала диагностики
- Рекомендует только платформы, доступные в РФ без VPN
- Показывает карьерные перспективы после прохождения трека
- Ищет реальные курсы на Stepik с фильтрацией по бюджету (5/4/3/2 курса в зависимости от уровня)
- Отклоняет нерелевантные запросы и просит уточнить цель

## Планируется

- Поиск статей через парсинг Habr
- Захардкоженный список курсов онлайн-школ (Skillbox, GeekBrains, Яндекс Практикум)
- Практические задания после каждого этапа
- Проверка выполнения заданий через ИИ
- Сохранение прогресса (личный кабинет)

## Стек

- Python 3.13
- Streamlit — веб-интерфейс
- GigaChat API (Сбер) — ИИ-ядро
- Stepik API — поиск реальных курсов

## Установка и запуск

1. Клонировать репозиторий:
```
git clone https://github.com/her1on/progressors.git
cd progressors
```

2. Создать виртуальное окружение и установить зависимости:
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

3. Создать файл `.env` и добавить ключ GigaChat:
```
GIGACHAT_AUTH_KEY=твой_ключ
```

4. Запустить приложение:
```
streamlit run app.py
```

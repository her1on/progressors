# Кванториум — план интеграции

## Концепция

Один бот с двумя режимами:
- **Обычный пользователь** — текущий функционал без изменений
- **Ученик Кванториума** — отдельный режим с детским контентом, закрытый по инвайт-коду

Когда Кванториум подтвердит интерес — выделяем в отдельный инстанс.

---

## Вход в режим Кванториума

- При `/start` добавить кнопку **"Ученик Кванториума"**
- При нажатии — запрашивать инвайт-код
- Инвайт-коды генерируем сами, передаём куратору Кванториума (без интеграции с их системами)
- Все коды хранятся в Supabase (новая таблица `kvantorium_codes`)

---

## Отличия режима Кванториума

| Параметр | Обычный | Кванториум |
|---|---|---|
| Тон промптов | Взрослый | Детский, мотивирующий |
| Источники | YouTube, Stepik, Habr и др. | Только релевантные для детей |
| Темы | Любые | Белый список (IT, техническое творчество) |
| Лидерборд | Общий | Только среди учеников |

---

## Личный кабинет ученика

- Текущий трек
- Прогресс по этапам
- Раздел заданий от куратора (куратор загружает вручную на первом этапе)

---

## Практические задания

MVP: куратор вручную следит за прогрессом каждого ученика и загружает задания персонально.
Автоматизация (LLM-тесты по теме этапа) — после подтверждения интереса от Кванториума.

---

## Архитектура (white-label)

Конфигурируемые параметры через env / конфиг-файл:
- Название и приветствие бота
- Тон промптов
- Список источников
- Белый список допустимых тем

# Прогрессоры — контекст проекта

Telegram бот, персональный ИИ-навигатор по обучению. Хакатон True Tech Arena.
Жюри оценивает по 4 критериям: 35+20+25+10 баллов.

## Критические правила

- **НИКОГДА не менять LLM модель без явного разрешения пользователя. Модель: `gpt-5.4`**
- Все ответы — на русском языке
- Хостинг на Railway — деплой происходит автоматически при push в ветку telegram-bot

## Технический стек

- Python 3.13, aiogram 3.13.1, webhook на Railway
- Codex API (OpenAI-совместимый), модель `gpt-5.4`, base_url `https://codex.sale/v1`
- YouTube Data API v3 — верификация видео (реальные ссылки через API)
- Stepik публичный API — верификация курсов
- Redis (RedisStorage) — FSM persistence между деплоями
- GitHub: her1on/progressors, ветка `telegram-bot`
- GitLab хакатона: git.truetecharena.ru (HTTPS + PAT, push в main через MR)

## Файлы проекта

- `bot.py` — все хендлеры, FSM, логика
- `bot_prompts.py` — все промпты (validate, specialize, questions, track, simplify, advance, alternative)
- `llm_client.py` — клиент Codex API, модель gpt-5.4, retry логика
- `youtube.py` — YouTube Data API v3
- `stepik.py` — Stepik публичный API
- `level.py` — parse_questions (парсинг JSON вопросов)
- `requirements.txt` — openai, aiogram==3.13.1, fastapi, uvicorn, redis[asyncio]

## FSM States (порядок онбординга)

1. `Form.goal` — ввод цели
2. `Form.specialization` — выбор направления (только для ШИРОКИЙ целей)
3. `Form.hours` — часы в неделю (кнопки: 2/5/10/20+)
4. `Form.months` — срок (кнопки: 1/3/6/12 мес)
5. `Form.motivation` — мотивация (пропускается для УЗКИЙ)
6. `Form.format_pref` — формат материалов (пропускается для УЗКИЙ)
7. `Form.quiz` — 4 вопроса диагностики уровня
8. `Form.track` — просмотр и навигация по треку

## Реализованный функционал

### Онбординг
- Валидация цели: РЕАЛИСТИЧНО / АБСТРАКТНО / ИНСТИТУЦИОНАЛЬНЫЙ / НЕРЕАЛИСТИЧНО
- Классификация масштаба: УЗКИЙ / ШИРОКИЙ (через LLM, не захардкожено)
- Специализация для широких целей: LLM генерирует 3 направления кнопками
- Пропуск мотивации и формата для узких целей (дефолты: Личное обучение / Любой формат)
- Предупреждение если hours × weeks < 20 для широкой цели (кнопки: продолжить / изменить время)
- 4 вопроса квиза → уровень: Полный новичок / Базовые знания / Средний / Продвинутый
- Профиль пользователя показывается перед построением трека

### Трек
- Адаптивное количество этапов по объёму часов: <20ч→1-2, 20-60ч→2-3, 60-120ч→3-5, >120ч→4-8
- Каждый этап: заголовок, длительность, темы, материалы, результат
- YouTube API верификация (реальные видео через API)
- Stepik API верификация (реальные курсы через API)
- Habr — поисковые ссылки (fallback)
- Итог: "Карьерные перспективы" для широких целей, "Что ты умеешь" для узких

### Навигация по треку
- ✅ Пройдено — добавляет в completed[], переходит к следующему этапу
- 😕 Сложно — LLM упрощает этап (simplify_prompt), пересоздаёт topics+materials
- 😊 Просто — LLM усложняет этап (advance_prompt), пересоздаёт topics+materials
- 👎 Не подошло — LLM даёт альтернативные материалы (alternative_prompt)
- ⬅️ Назад / ➡️ Следующий — edit_text в том же сообщении (без дублирования)

### Команды
- `/start` — начать/перезапустить
- `/progress` — прогресс-бар текущего трека (✅▶️⬜), цель, уровень, этапы
- `/cancel` — сброс FSM состояния
- `/help` — справка

## Ключевые технические решения

- `_validate_goal` возвращает `(status, explanation, scope)` — scope: "узкий" | "широкий"
- `_split_llm_response` — делит ответ LLM на topics/materials по строкам `[YouTube|Stepik|Habr|Rutube|VK]`
- `_cancel_user_tasks` — отменяет фоновые asyncio задачи при рестарте
- `_proceed_after_months` — helper разветвления: узкий→квиз, широкий→мотивация
- `_resolve_questions_and_start_quiz` — получает вопросы (из фонового таска или свежим запросом)
- Фоновая генерация: `asyncio.create_task` для вопросов и трека параллельно с онбордингом
- `edit=True` в `_send_stage` — навигация без дублирования сообщений
- `escape_md` экранирует `*_\`[()` для Telegram Markdown
- `LinkPreviewOptions(is_disabled=True)` — отключение превью ссылок
